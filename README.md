# Chess Engine
A c++ chess engine with a web app to use it. 

## Motivation
It would be cool to name a chess engine that was actually good and I figured I would have to get better with chess notation by doing this project (which I have).

## Current Challenge
Move generation based off of the board. 

## Background
This chess game will be a bit board approach. I will generate moves and occupancies and store them in unsigned long long variables. In terms of the actual engine that is still to be determined as I figure out the game control itself. I will start with a minimax and alpha beta pruning approach with a simple material difference, king safety, piece placement formula but am curious about ML approaches as well as other simulation techniques.
